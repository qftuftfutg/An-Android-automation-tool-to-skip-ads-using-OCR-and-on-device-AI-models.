## 安全设计原则

- AI 不得直接授权点击；AI 结果只用于诊断或高风险否决。
- 开屏广告分类本身不能成为点击许可。
- 观察模式只记录，不执行点击。
- 截图应按项目设计保存在短生命周期的内存隔离区，不应进入共享存储或上传。
- OCR/AI 超时后应丢弃迟到结果，并继续走安全的原生规则检查。
- 正文、标题中提到“跳过”不能触发广告跳过。
