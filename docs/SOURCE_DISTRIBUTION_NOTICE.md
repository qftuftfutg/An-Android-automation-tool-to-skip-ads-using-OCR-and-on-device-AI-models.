# 源码分发调整说明（1.7.0-clean-source）

整理日期：2026-10-30

## 调整目的

当前公开源码分发版有意与第三方广告规则文件及其专有格式解耦。此调整是工程范围和来源管理措施，不是对任何既有法律争议的法律结论，也不构成“免责保证”。

## 已从当前可执行源码中剥离

| 项目 | 处理 |
|---|---|
| `RuleImporter.kt` | 整个第三方规则导入/规范化实现已删除 |
| `MainActivity.kt` | 移除规则文件选择器、导入预览/确认流程、规则导入统计 UI 和相关缓存读取 |
| `AdGuardAccessibilityService.kt` | 移除第三方导入规则执行方法、兼容字段处理、应用包名哈希匹配及相关匹配语法解析 |
| 数据字段 | 不再读取/执行历史偏好项 `imported_rules_json`；旧版遗留值不会进入当前规则执行路径 |
| 上游文件 | 当前 ZIP 不包含李跳跳 APK、反编译产物、第三方规则 JSON 或社区规则数据集 |

删除的第三方 JSON 字段/概念包括：`popup_rules`、`keywords`、`keywords_append`、第三方数字包名哈希映射，以及与该兼容层绑定的 `=` / `+` / `-` / `&` 规则表达式解释。

## 截图与标注数据边界

- 无障碍自动识别链路使用的屏幕截图按短生命周期内存对象处理；此设计不等同于“整个应用从不保存图片”。
- 人工标注工具通过用户选择导入的原图会按标注功能需要持久保存在应用私有目录，直到用户清理应用数据或删除对应记录。
- 用户主动导出的数据集 ZIP 可被保存到应用沙箱之外；导出后的文件由用户和目标存储位置管理。
- 因此，隐私说明应区分自动识别截图、标注原图和用户导出文件，不应笼统宣称所有截图都不会落盘或永远不会离开应用。

## 当前仍保留

- Android Accessibility Service 等 Android 官方平台能力。
- 清屏自身维护的应用专属识别条件、短标签识别、开屏时间窗口、控件范围及点击安全门。
- 清屏自有的 OCR、AI 诊断、观察模式、日志和统计。

内置识别规则仍可能包含应用包名、控件位置和短标签条件。这些是清屏自身功能逻辑，并不等于第三方规则文件兼容功能仍然存在。对于任何保留的应用专属规则，仍需逐项审核其来源、必要性与合法性。

## 公开文档中的历史说明

项目 CHANGELOG、历史问题记录及审计文档中可能继续出现“李跳跳”“规则导入”等文字。这些内容是对早期开发行为、排错过程或来源审计的历史事实记录，保留它们是为了不篡改项目历史。

**它们不是当前源码功能清单。** 当前分发源码不含上述兼容导入器，也不应再宣传为支持导入李跳跳规则。

## 验证声明

本次完成了源码静态修改、ZIP 解包/重打包和字符串/引用扫描。当前环境没有完成 Android Gradle 编译、单元测试运行或真机回归，因此不能声称修改后的 APK 已构建成功，也不能声称所有运行时路径已经验证。

建议维护者在 Android Studio 中先构建并检查：

1. 首页不再出现第三方规则导入按钮。
2. 旧版安装升级后，残留 `imported_rules_json` 不再被执行。
3. 清屏内置应用专属跳过规则仍能进入安全门。
4. 抖音正文/标题包含“跳过”时仍不会点击。
5. 观察模式下不执行点击。
